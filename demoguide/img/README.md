# Demo Guide Images

This directory contains screenshots and images for the demo guide.

## Recommended Images to Add

When documenting your demo, consider adding screenshots of:

1. **Resource Group Overview** - Shows all deployed resources
2. **ML Workspace Studio** - Main ML Studio interface
3. **Compute Instance** - Running compute instance in the workspace
4. **Virtual Network Configuration** - Network topology with subnets
5. **Storage Account Integration** - Datastores configuration
6. **Container Registry** - Private registry setup
7. **RBAC Assignments** - Role assignments for managed identities

## Image Naming Convention

Use descriptive names for images:
- `resource-group-overview.png`
- `ml-studio-interface.png`
- `compute-instance-running.png`
- `network-topology.png`
- `storage-datastores.png`
- `container-registry.png`
- `rbac-assignments.png`

## Usage in Markdown

Reference images in the demo guide using:
```markdown
<img src="img/resource-group-overview.png" alt="Resource Group Overview" style="width:100%;">
```
